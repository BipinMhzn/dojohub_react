# TournamentBracket

**File:** `app/System/Tournament/Models/TournamentBracket.php`  
**Namespace:** `App\System\Tournament\Models`  
**Table:** `tournament_brackets`  
**Extends:** `AppBaseModel`

A bracket defines the competition structure for one tournament category. One bracket per category. Generated by `BracketService` from the registered competitors.

---

## Fillable

| Column | Type | Notes |
|--------|------|-------|
| `tournament_category_id` | `ulid` | FK → `tournament_categories.id` |
| `type` | `BracketTypeEnum` | Competition format |
| `seeding_method` | `SeedingMethodEnum` | How competitors are seeded |
| `competitor_count` | `integer\|null` | Set by system on generation |
| `round_count` | `integer\|null` | Set by system (log2 of next power of 2) |
| `status` | `BracketStatusEnum` | Set by system |
| `generated_at` | `datetime\|null` | Timestamp of bracket generation |

## BracketTypeEnum

| Case | Value | Notes |
|------|-------|-------|
| `SingleElimination` | `0` | Implemented |
| `DoubleElimination` | `1` | Implemented (same algorithm as single) |
| `PoolFinal` | `2` | Not yet implemented |
| `Repechage` | `3` | Not yet implemented |

## BracketStatusEnum

| Case | Value |
|------|-------|
| `Pending` | `0` |
| `Active` | `1` |
| `Completed` | `2` |

---

## SeedingMethodEnum

| Case | Value |
|------|-------|
| `Random` | `0` |
| `Manual` | `1` |
| `ByRank` | `2` |

**Note:** Seeding is currently always applied as: top 3 by insertion order → remainder randomly shuffled, regardless of `seeding_method` value.

---

## One bracket per category

`BracketRepository::getBracketByCategory()` returns the existing bracket or `null`. Attempting to generate a second bracket is blocked in `MatchesController::generate()`:

```php
if ($this->bracketRepository->getBracketByCategory($categoryId)) {
    return back()->with('error', 'Bracket already generated for this category.');
}
```
